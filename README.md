# Console Accumulator

Консольное приложение на C# для последовательного накопления суммы вводимых чисел.

## Функциональность

- Бесконечный цикл ввода чисел
- Накопление суммы всех введённых чисел
- Защита от некорректного ввода (TryParse)
- Выход по команде "Q"
- Вывод текущей суммы после каждого ввода

## Пример работы

Введите число: 10
сумма = 10
Введите число: 25.5
сумма = 35.5
Введите число: abc
Введите число: 14
сумма = 49.5
Введите число: Q

## Куда можно встроить

- В калькуляторы с накоплением
- В системы учёта расходов
- В обучающие примеры по циклам

## Требования

- .NET Core / .NET Framework
- Консольное приложение

## Примечание

Некорректный ввод игнорируется, сумма не меняется.
